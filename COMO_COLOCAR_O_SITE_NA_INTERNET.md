# Como Publicar este Site na Internet (Gratuito e em 1 Minuto)

Este site foi construído em arquitetura estática moderna (HTML5 + CSS3 + JavaScript puro).  
Isso significa que você **não precisa pagar servidor** nem configurar banco de dados na nuvem para colocá-lo no ar.

---

### Opção 1: Netlify Drop (Mais Fácil - Leva 30 Segundos)
1. Acesse: **[app.netlify.com/drop](https://app.netlify.com/drop)**
2. Arraste a pasta inteira **`Site_Eleicoes_RJ_2026`** para dentro do navegador.
3. Pronto! O Netlify criará um link público instantâneo (ex: `https://eleicoes-rj-2026.netlify.app`) que você poderá enviar por WhatsApp para assessores, equipe e eleitores acessarem no celular ou computador.

---

### Opção 2: Vercel
1. Acesse: **[vercel.com](https://vercel.com)**
2. Crie uma conta gratuita e faça upload da pasta `Site_Eleicoes_RJ_2026`.
3. O site estará disponível em segundos com certificado SSL (HTTPS) automático.

---

### Opção 3: GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta (`index.html`, `dados_dashboard_2026.js`).
3. Em **Settings > Pages**, selecione a branch `main` e salve.
4. O site ficará no ar em `https://seunome.github.io/repositorio/`.

---

### Uso Local (Sem Internet)
* Basta dar um duplo clique no arquivo: **`abrir_site.bat`** (ou abrir diretamente o **`index.html`**).
* Para rodar como servidor local e compartilhar pelo Wi-Fi do escritório: execute **`iniciar_servidor_local.bat`**.
